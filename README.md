# 🎬 TABI EDIT (iOS IPA)

**TABI EDIT** is a native iOS 1080p 60FPS Video Quality Enhancer & Editor built with SwiftUI, AVFoundation, and CoreImage.

### ✨ Features
- **🔥 CapCut Default 1 & Default 2 Presets:** 1-click quality enhancement with Brightness, Contrast, Saturation, Brilliance, Sharpness, and 5-channel HSL Saturation controls.
- **✂️ Video Split & 🗑️ Delete:** Split clips at the playhead and delete unwanted segments on the timeline.
- **🎬 Fade-In Animation:** Smooth customizable black-to-video fade-in animation (`0.3s - 3.5s`).
- **🎙️ Voice Overlay & Audio Mixer:** Record live microphone voiceover or import audio files and mix with original video volume.
- **🚀 1080p 60FPS Export:** Saves directly to iPhone Photos or shares via iOS Share Sheet.
